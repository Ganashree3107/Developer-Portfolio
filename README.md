# Ganashree — Developer Portfolio

My personal portfolio website. It introduces who I am, the tools I work with, and three projects I've built. It's a single responsive page that works on phones, tablets and desktops.

## Built with

- [React](https://react.dev/) + [Vite](https://vitejs.dev/)
- Custom CSS (with Tailwind's base styles)
- [Lucide](https://lucide.dev/) icons

## Run it locally

You need [Node.js](https://nodejs.org/) (LTS) installed.

```bash
npm install
npm run dev
```

Then open the address Vite prints (usually `http://localhost:5173`).

## Build for production

```bash
npm run build
```

The finished site is created in the `dist/` folder, ready to deploy to Netlify, Vercel or any static host.

## Project structure

```
src/App.jsx      Page content and sections
src/styles.css   All styling, including phone and tablet layouts
public/          Favicon and other static files
index.html       Page title, description and fonts
```

`reference-omnifood-index.html` is the original OmniFood page, kept for reference only. It isn't part of the portfolio build.
